# Aviso de Demonstração

Este projeto é uma demonstração pública de portfólio e utiliza somente dados fictícios.

A demo não realiza diagnóstico real, não coleta dados pessoais, não envia respostas, não possui autenticação ou banco de dados reais e não executa cálculos oficiais. Ela não substitui avaliação técnica, jurídica, ocupacional ou de segurança do trabalho.

O código-fonte do produto comercial, regras proprietárias, banco de dados, credenciais e demais componentes sensíveis não fazem parte desta versão.

Todos os direitos reservados.
